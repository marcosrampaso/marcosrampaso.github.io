Predicting Dota 2 match winners

I used a 9,264-match course subset of the UCI Dota 2 dataset to study whether hero lineups and match settings could predict the winning team. I set up cross-validation for k-nearest neighbors, support vector machines, and random forests on the original features and on principal component analysis (PCA) projections with 2, 8, 16, 32, or 64 components.

I compared classification accuracy and runtime as the number of components increased. Rerunning the coursework requires the prepared course CSV and its evaluation helper.

Video game age ratings

I used content descriptors from 1,895 games to predict four ESRB rating categories. I compared decision trees, random forests, support vector machines, and k-nearest neighbors using stratified cross-validation and reviewed class-level errors.

The random forest reached a mean macro F1 of 0.87 across ten folds. In the notebook’s 379-game holdout experiment, Everyone 10+ had the lowest F1 for both the random forest and the decision tree.

Handwritten digit recognition

I visualized 1,500 digit images with principal component analysis and tuned KNN and SVM classifiers using separate validation data within each training fold. On ten stratified folds, mean accuracy was 88% for SVM and 84% for KNN.

View the digit recognition notebook ↗

An interpretable classifier for iris species

I used exploratory plots to choose petal width and implemented a threshold classifier for two iris species. Over 20 stratified train/test splits, fitting the threshold on each training set yielded mean test accuracy of 94.7%.
