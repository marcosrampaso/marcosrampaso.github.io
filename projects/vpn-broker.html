VPN Broker

I designed and built a shared API that provisions VPN profiles and credentials on demand through time-limited leases.

Replacing per-deployment configuration

Each deployment previously relied on its own VPN configuration bundle. I built the VPN Broker to centralize provisioning so deployments could request a profile and credentials when a workflow needed VPN access.

How a lease works

RequestA client requests VPN access when it needs a connection.
ProvisionThe broker returns a profile and credentials under a time-limited lease.
ConnectThe client uses the leased profile to establish an OpenVPN connection.

I implemented the API in C# with ASP.NET Core on .NET 10, PostgreSQL, and Entity Framework Core. I also built a .NET SDK with a local fallback and automated OpenVPN health checks and recovery.

From pilot to production

The service was piloted in Mexico and enabled across six production Kubernetes deployments configured for VPN access in Brazil, Mexico, and the United States. The broker handled about 66,500 lease requests in a 30-day period.
